# 问题二：最终最优结果

本目录收录当前统一验证协议下选出的最优结果。当前模型由 DeBERTa-v3-small 文本分支与三模态 token 交互 Transformer 组成，并按文本实际可用比例动态调整融合权重。使用完整 CMU-MOSEI 的安全训练集（16,326 条）和视频组隔离验证集（1,871 条）；附件3及测试标签未参与训练、融合参数选择或模型选择。

第二问四项题目要求的统一说明见 `../../../question2/问题2_最终模型与四项结果说明.md`；附件3全量预测的正式CSV是 `../问题2_附件3最终最优预测/问题2_附件3提交版预测.csv`，30条样本已全部生成。逐样本概率和缺失信息、结果图及核验文件也在该附件3目录。当前最优模型的验证错误归因新增于 `当前最优_DeBERTa自适应融合/错误归因/`。历史固定文本融合附件3文件仅用于对照。

本组最终实验运行在服务器的 **1 号显卡（`cuda:1`）**：**NVIDIA RTX A6000，49140 MiB（约 48 GiB）显存**。

## 当前验证结果

- 干净验证集 Macro-F1：**0.6709016229**
- 干净验证集 Accuracy：**0.7017637627**
- 干净验证集 MAE：**0.4924424162**
- 连续缺失场景平均 Macro-F1：**0.6476891472**
- 散点 TAV 缺失平均 Macro-F1：**0.6236501372**
- 综合鲁棒选择分数：**0.5980107662**
- 视频组隔离融合留出集 Macro-F1：**0.6925512642**（158 个视频，未参与融合参数选择）
- 分类别召回率：负向 **0.7549**、中性 **0.4988**、正向 **0.7672**；中性类别是当前主要误差来源。

相较上一版跨模态模型，干净 Macro-F1 提升 0.03081，综合鲁棒选择分数提升 0.02776。
