# 问题2：附件3全量预测与结果解读

以 GitHub `outputs/question2/最终最优结果/README.md` 指定的 DeBERTa-v3-small 文本分支与跨模态交互 Transformer 自适应融合模型为准，使用已在视频组隔离校准集确定的参数直接推理附件3的30条对齐特征样本。类别编码为负向0、中性1、正向2。

## 结果文件

- `问题2_附件3提交版预测.csv`：30条样本编号、类别编码、极性及类别一致的情感强度。若题目方提供提交模板，应按模板列名重排后提交。
- `问题2_附件3全量预测.csv`：额外保存三类概率、原始回归强度、两分支预测、融合权重、模态缺失比例和被屏蔽的联合UNK数；不包含原始特征或文本内容。
- `逐样本预测/`：每条样本的独立记录。
- `问题2_附件3预测分析.json` 与 `问题2_附件3推理核验.json`：汇总统计、模型与数据哈希、可复核检查。
- `结果图/`：30条样本概率图、类别分布与缺失置信度图，各有PNG、SVG、PDF及TIFF格式。所有30条样本均绘入图中，柱段未使用白色边线。

## 主要发现

预测为负向6条（20%）、中性9条（30%）、正向15条（50%）。最大类别概率平均0.6635，中位数0.6465。这些概率是模型输出，不等同于经过附件3标签验证的正确率。最大概率低于0.5的样本为08、13、18、22、24、28，其中22最低（0.3778）；它们适合优先人工复核，不能仅凭概率直接改标签。

三模态在有效内容位置上的平均不可用比例分别为文本20.67%、语音20.67%、视觉21.09%。共131个联合UNK且语音、视觉同时不可用的位置已在编码前屏蔽，以免缺失文本泄漏到上下文特征。两分支在7条样本上的最优类别不同（11、13、21、23、25、28、30），说明这些样本存在模态证据分歧。样本24的可观测文本只剩下短句，预测负向的最大概率为0.4498，尤其不宜写成确定性结论。

相对单独的跨模态分支，对附件3发生类别变化的仅13和25，均由正向变为中性。13的最终最大概率仅0.4457，应优先复核；25为0.6329。由于附件3没有公开真实标签，无法判定这两处变化是否修正了错误，也不能计算附件3的Accuracy、F1、MAE或宣称提升。GitHub当前最优方法的70.18% Accuracy、67.09% Macro-F1、0.4924 MAE均来自视频组隔离的有标签验证集，不是附件3测试指标。

## 推理核验

30个文件对应30个唯一编号；模型权重SHA-256与GitHub最优结果说明一致；概率均有限且和为1；重复推理逐值一致；全程未加载附件3标签。推理进程结束后，1号RTX A6000显存占用回到0 MiB。提交强度按类别符号约束生成（负向≤-0.01、中性=0、正向≥0.01），原始回归输出同时保存在全量CSV中，便于检查后处理影响。
