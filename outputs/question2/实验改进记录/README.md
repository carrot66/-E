# 问题二改进实验记录

本目录保存围绕问题二进行的受控改进实验。所有实验都只使用 `work/full_mosei/safe_train_valid.pkl` 的 16,326 条训练样本和 1,871 条验证样本；附件 3 测试标签没有参与训练、阈值选择或模型选择。

## 当前采用的模型

`最终最优结果` 仍采用跨模态交互 Transformer：每个对齐位置形成文本、语音、视觉三个模态 token，经两层八头跨模态 Transformer 和两层时间 Transformer 聚合。当前最佳验证结果为：完整样本 Macro-F1 **0.640094**，鲁棒选择分数 **0.570250**。检查点保存在 38001：

`outputs/question2/问题2_跨模态交互完整优化/问题2_跨模态交互完整优化_best.pt`

## 已执行的改进及结论

| 实验 | 改动 | 完整 Macro-F1 | 选择分数 | 是否替换 |
|---|---|---:|---:|---|
| 鲁棒 V2 质量门控 | 模态可用率、局部连续性门控；视频组逆频率采样；质量加权回归 | 0.622720 | 0.555043 | 否 |
| 残差质量门控 | 有效模态保留至少 50% 残差信息；减弱组均衡 | 0.629511 | 0.556038 | 否 |
| 轻度类别/视频组平衡 | 中性类和长视频片段轻度重采样 | 0.631876 | 0.554622 | 否 |
| 焦点损失基线 | 对难样本使用 focal CE，保持原跨模态结构 | 0.625608 | 0.560182 | 否 |

这些实验说明当前瓶颈主要在固定 BERT 表示和标签噪声，而不是简单的采样、门控或焦点损失。新增模型检查点均保留在 38001 的对应实验目录，轻量日志和指标在本目录下同步保存；没有用低于基线的模型覆盖最终结果。

## 阈值诊断

对最终模型做了验证集偏置探测。中性偏置约 `+0.025`、正类偏置约 `-0.075` 时，验证集 clean Macro-F1 可到 0.645089，但这是在同一验证集上搜索的诊断结果，不能当作独立泛化指标，因此没有把它作为最终模型成绩。

## 下一步可行方向

如果要继续冲击 0.66 以上，应优先做带视频组交叉验证的 BERT 末层微调或 LoRA，并把校准偏置只在组隔离的训练折上学习；单纯继续加大缺失增强会损害完整样本 F1。
