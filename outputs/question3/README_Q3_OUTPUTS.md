# 问题3输出说明

以下目录对应题目要求的五类交付内容。

## 01_建模原理与训练方案

包含 v5 模型与训练说明、训练配置、模型参数清单、候选模型训练记录、训练曲线和模型比较图。`模型参数/component_0.pt` 是正式部署组件，`manifest.json` 记录权重、代码选择和 BERT 指纹。

## 02_典型样本解释卡

包含附件4的 20 个 HTML 解释卡和浏览入口。每张卡展示预测类别、连续强度、三模态 Shapley 作用、主要参考模态、局部证据和遮挡影响；音视频时间未经过外部核验的位置不会伪造秒级定位。

## 03_局部重要性与模态对比

包含 20 个附件4样本的局部重要性图、模态比较图、忠实度图、局部窗口表、关键证据表和 8 子集输出。目录中的 `.drawio` 文件可以在 diagrams.net 中继续编辑。

## 04_附件4全量预测与解释

包含附件4全部 20 条样本的类别概率、连续强度、模态贡献、视频映射、8 子集结果、局部窗口证据和解释审计。

## 05_验证集评价与错误归因

包含 728 条验证集预测、逐类别指标、混淆矩阵、回归散点图、候选模型比较、重复种子统计、错误分层和数值审计。`quality_audit.json` 中的 `numerical_audit` 为 `passed`。错误人工复核表保留可观测字段，人工原因没有被编造。

## 结果口径

正式验证集：Accuracy `0.6634615385`，Macro-F1 `0.6432399504`，Weighted-F1 `0.6646764494`，MAE `0.5832294822`，Pearson `0.6607026983`。验证集参与了模型选择和固定类别偏置选择，因此这些数值不是独立测试成绩；附件4没有标签，不报告准确率。
