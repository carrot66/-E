# 问题2：最终模型与四项结果说明

本说明以 `outputs/question2/最终最优结果/README.md` 指定的当前最优方法为准。旧文档 `问题2_鲁棒性模型与结果说明.md` 描述的是此前的门控蒸馏与固定文本融合实验，其数值和附件3路径不能作为本次最终答案。附件3没有真值标签，预测结果不能用于计算测试集 Accuracy 或 F1。

## (1) 建模原理、网络结构、目标函数和训练

输入为词位对齐的文本、语音、视觉特征，维度分别为768、74、35。先根据 `[CLS]`/`[SEP]` 确定有效内容，再为每个词位建立三模态可观测掩码。联合 `[UNK]` 且同位置语音、视觉全零时判为共同缺失；缺失词在 BERT 编码前遮蔽，避免隐藏内容经上下文表示泄漏。训练集可观测位置拟合标准化统计量，验证和附件3只复用它。

最终模型包含两个分支。跨模态分支把每个词位的三模态投影到128维，经2层8头模态交互 Transformer、2层8头时序 Transformer、掩码注意力池化，输出三分类概率及范围为[-3,3]的情感强度。文本分支使用 DeBERTa-v3-small，微调最后3层及分类/回归头；对缺失文本先只保留可观测 token，再送入 DeBERTa。两分支的类别对数概率按文本实际可用比例动态融合：有效文本权重 `0.675 × 可观测文本比例`，另对中性、正向 logit 加固定偏置 `+0.12`、`−0.02`。强度按相同权重融合。三个融合参数只在821条、142个视频的校准组选择；1050条、158个视频的留出组未参与选择，视频组交集为0。

跨模态分支优化平方根类别频率加权交叉熵、`0.6×Smooth-L1` 强度损失，以及对合格的增强样本施加教师蒸馏 KL（温度2）与回归蒸馏；附加序数与监督对比损失的权重在选定配置中为0。训练增强混合35%完整、30%连续模态缺失、35%散点共同缺失。AdamW学习率`2e-4`、batch 64、dropout 0.2、梯度裁剪1，最多24轮、提前停止耐心6轮，最佳权重在第5轮。文本分支使用类别加权、标签平滑交叉熵加`0.15×Smooth-L1`，训练时约30%样本做词元遮蔽；编码器/头学习率分别为`1.5e-5`/`2e-4`，batch 32、dropout 0.15，最多8轮、最佳第4轮。两分支均只用安全的完整 MOSEI train 16,326条训练，以视频组隔离的 valid 1,871条选模；完整 test 与附件3标签均未进入训练/调参。

代码：`q2_crossmodal_full_experiment.py`、`q2_deberta_text_experiment.py`、`q2_deberta_ensemble.py`、`q2_deberta_robust_ensemble.py`。最终 DeBERTa 文本权重和跨模态权重已通过 Git LFS 上传 GitHub；权重哈希与详细参数见 `outputs/question2/最终最优结果/README.md` 及相应配置 JSON。

## (2) 缺失类型、缺失率及消融

同一验证集上的分支消融：仅跨模态分支 Accuracy **67.24%**、Macro-F1 **64.01%**、MAE **0.5330**；仅DeBERTa文本分支为 **69.21%**、**65.39%**、**0.5146**；固定参数融合为 **70.18%**、**67.09%**、**0.4924**。这支持两个分支存在互补信息，但并不等于附件3测试集的实测提升。参数校准/视频留出分组及各分支指标保存在 `问题2_视频组隔离融合结果.json`。

最终模型在30%连续缺失时，完整输入 Macro-F1 **0.6709**，仅缺文本T为 **0.6158**，仅缺语音A为 **0.6681**，仅缺视觉V为 **0.6679**，语音加视觉AV为 **0.6692**，三模态TAV为 **0.6175**。文本缺失的影响明显更大。散点TAV缺失率由10%增至20%、30%时，两次固定掩码重复的平均 Macro-F1 依次约为 **0.6418、0.6181、0.6110**。这说明在已评估范围内性能随共同缺失增加而下降；更高缺失率尚未对最终模型验证，不能把旧模型的50%/70%结果冒充为最终模型结果。

完整场景CSV在 `outputs/question2/最终最优结果/当前最优_DeBERTa自适应融合/问题2_缺失场景全量结果.csv`；同目录 `plots/` 有缺失类型、缺失率、模型对比和训练曲线图。历史网络、训练增强等更多消融在 `outputs/question2/实验改进记录/` 中，需与当前最优模型的结果区分。

## (3) 附件3全量预测

`outputs/question2/问题2_附件3最终最优预测/问题2_附件3提交版预测.csv` 包含全部30条的编号、类别编码、极性、强度；`问题2_附件3全量预测.csv` 另含三类概率、原始回归强度、分支预测、可用率和被屏蔽UNK数，不包含原始特征或文本内容。30条分别预测负向6、中性9、正向15。平均最大类别概率0.6635；08、13、18、22、24、28六条低于0.5，应优先人工复核。`结果图/` 提供逐条概率和缺失—置信度图，`结果说明.md` 给出更详细解读。附件3没有标签，因此这些是**预测**，不是测试集性能指标。

推理核验：30个唯一编号，概率有限且和为1，重复推理逐值一致，131个共同缺失UNK位置被屏蔽，权重SHA-256与保存的最佳权重一致。模型原始回归强度与类别一致的提交强度均保留；中性提交强度置0，负向不高于-0.01，正向不低于0.01。

## (4) 验证性能、可视化和错误归因

视频组隔离的完整验证集共1,871条，最终 Accuracy **0.7018**、Macro-F1 **0.6709**、Weighted-F1 **0.7017**、MAE **0.4924**。视频组隔离融合留出组 Macro-F1 **0.6926**，但它属于验证集内部的参数留出，不是附件3测试指标。逐轮训练、归一化混淆矩阵、缺失率与模型对比图均位于当前最优结果的 `plots/`。

根据全部1,871条逐样本验证预测重新计算，正确1,313条、错误558条。负向、中性、正向召回率分别为 **75.49%、49.88%、76.72%**；中性误判中有144条被判为正向，是主要类别边界问题。另有74条误判的最高模型概率至少0.8，说明不能把输出概率直接当作可靠的正确率。真实强度绝对值达到1.5的322条样本 MAE **0.8410**，明显高于低强度组，提示强情绪强度回归更难。这些属于验证集上的关联和错误模式，不能仅凭统计归因为标注错误或某一模态的因果作用。

`outputs/question2/最终最优结果/当前最优_DeBERTa自适应融合/错误归因/` 保存重算汇总、高置信误判样本、大强度误差样本；生成脚本为 `q2_selected_validation_audit.py`。原始逐样本验证预测和模型参数仍在当前最优结果目录，便于复核。

## 提交与限制

本仓库同步代码、CSV、JSON、图、说明和最终两份 Git LFS 权重，不包含原始视频、完整 MOSEI 压缩包或缓存。首次克隆后运行 `git lfs pull` 获取权重实体文件。竞赛提交时还应按官方论文和附件命名规范整理，并人工复核低置信度附件3样本及最终文字表述。这里的四项材料已形成可提交基础，但不能宣称附件3实测准确率，也不能把验证集结果写成隐藏测试集结果。
